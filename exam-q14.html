📄 Question

A class has 4 ground-truth objects. Ranked detections (confidence ↓), TP if IoU ≥ 0.5:

TP, FP, TP, TP, FP.

Q14(a) Fill running precision and recall after each detection. 3M

Q14(b) Interpolate (max precision for any recall \(\ge\hat{r}\)) and compute the PASCAL 11-point AP. 4M

Q14(c) If a second class has AP \(=0.40\), what is mAP? How does COCO’s AP differ? 1M

Solution — Q14(a)

RankCorrect?TP so farPrecisionRecall
1TP11/1 = 1.001/4 = 0.25
2FP11/2 = 0.500.25
3TP22/3 ≈ 0.672/4 = 0.50
4TP33/4 = 0.753/4 = 0.75
5FP33/5 = 0.600.75

Recall is non-decreasing; precision zig-zags (drops on an FP, can rise on a later TP). First duplicate of the same GT would also be FP.

Solution — Q14(b)

Interpolated \(P(\hat{r})=\max\{\,P : R\ge\hat{r}\,\}\). Sample at \(\hat{r}=0,0.1,\ldots,1.0\):

Recall knotsMax P to the right
0.0, 0.1, 0.21.00 (the first TP)
0.3, 0.4, 0.5, 0.6, 0.70.75 (rank-4 TP beats 0.67 and 0.60)
0.8, 0.9, 1.00 (never reached recall 1.0; max R = 0.75)
\[ \mathrm{AP}=\frac{3\times 1.00 + 5\times 0.75 + 3\times 0}{11}=\frac{3+3.75}{11}=\frac{6.75}{11}\approx\mathbf{0.614} \]
Answer

\(\mathrm{AP}\approx0.61\). Interpolation turns the orange zig-zag into a monotone staircase so a single ranking jitter does not crash the score. Method: rank → TP/FP → running P/R → interpolate → average 11 knots.

Solution — Q14(c)

Answer

\(\mathrm{mAP}=(0.614+0.40)/2\approx\mathbf{0.51}\). COCO additionally averages AP across IoU thresholds \(0.50:0.05:0.95\), which punishes loose boxes. PASCAL’s headline is AP @ IoU 0.5.

Answer

TP so far = 2, \(P=2/3\approx0.67\), \(R=2/5=0.40\). (Lecture row.)

P14.2 Lecture 11-point result: five knots at 1.0, four at 0.57, two at 0.5. AP? 2M
Answer

\((5\times1+4\times0.57+2\times0.5)/11=(5+2.28+1)/11=8.28/11\approx\mathbf{0.753}\).

P14.3 ROC vs PR: what does each plot, and what is a random classifier? 2M
Answer

PR: precision vs recall (the detection plot; AP = area). ROC: TPR vs FPR; random = diagonal, AUC 0.5; perfect = \((0,1)\). Discrete classifiers are a single point. Face verification often quotes TAR @ a fixed FAR instead.
