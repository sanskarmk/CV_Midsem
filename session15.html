Session 15

Object Tracking

A video is a stack of images — data is now a function of \((x,y,t)\). Tracking means locating a moving object over time. The lecture toolkit: motion detection, optical flow (Lucas–Kanade), tracking-by-detection, mean-shift / Camshift, Kalman filters, and DNN trackers (DeepSORT, FairMOT).

Motion detection vs object tracking

Motion detection asks “did something move?” (frame differencing, background subtraction, IR/microwave sensors that open a door). Object tracking asks “which object is this, and where is it now?” — identity over time. Applications: autonomous vehicles, surveillance, AR, traffic speed, visual SLAM (simultaneous localisation and mapping), super-resolution from a burst of frames.

Motion detection

  • Frame differencing — threshold \(|I_t - I_{t-1}|\). Cheap; fails with a moving camera and with slow objects.
  • Background subtraction (GMM) — model each pixel’s background as a mixture of Gaussians; anything that doesn’t fit is foreground. Classic for a static camera. Challenges: noise, lighting changes, moving cameras.
  • Motion segmentation — group pixels into coherently moving layers (not just fg/bg).

Uses of motion beyond tracking: stabilisation, super-resolution (register → warp to a common frame → fuse → optional deblur), event/activity recognition.

Optical flow

Optical flow is the apparent motion of brightness patterns — a vector field \((u(x,y), v(x,y))\) between two frames. Note: lighting change without physical motion still produces “flow.” Three key assumptions (from the slides):

  1. Brightness constancy — a point looks the same in every frame.
  2. Small motion — points don’t jump far (so a Taylor expansion is valid).
  3. Spatial coherence — neighbours share the same \((u,v)\).

Brightness constancy \(I(x,y,t)=I(x+u,y+v,t+1)\) plus small motion gives the optical-flow constraint:

\[ I_x u + I_y v + I_t = 0 \]

One equation, two unknowns — the aperture problem. Along an edge you can recover only the normal component of motion. Methods: Horn–Schunck (global smoothness over the whole image), Lucas–Kanade (local, small windows), Farnebäck (dense polynomial expansion, every pixel).

Lucas–Kanade

Lucas & Kanade, 1981. Assume \((u,v)\) is constant in a \(K\times K\) window (e.g. 5×5 → 25 equations). Overdetermined linear system; least squares:

\[ \begin{bmatrix} \sum I_x^2 & \sum I_x I_y \\ \sum I_x I_y & \sum I_y^2 \end{bmatrix} \begin{bmatrix} u \\ v \end{bmatrix} = -\begin{bmatrix} \sum I_x I_t \\ \sum I_y I_t \end{bmatrix} \]

The left-hand matrix \(A^\top A\) is exactly the Harris second-moment matrix \(M\). Solvable when \(M\) is invertible, both eigenvalues are large, and they are comparable — i.e. at corners. Flat: both \(\lambda\) small. Edge: one \(\lambda\) dominates. That is why KLT tracking follows Harris corners.

Worked numerical — when is flow solvable?

Q. In a window, \(\sum I_x^2=8,\ \sum I_y^2=8,\ \sum I_x I_y=0,\ \sum I_x I_t=-4,\ \sum I_y I_t=-4\). Compute \((u,v)\) and classify the patch. Repeat if \(\sum I_y^2=\sum I_x I_y=\sum I_y I_t=0\) and \(\sum I_x^2=8,\ \sum I_x I_t=-4\).

Window 1
\(M=\mathrm{diag}(8,8)\), invertible, \(\lambda_1=\lambda_2=8\) (corner). \((u,v)=(-4/8,-4/8)=(-0.5,-0.5)\).
Window 2
\(M=\mathrm{diag}(8,0)\), singular (edge). Only the \(x\)-normal flow \(u=-0.5\) is determined; \(v\) is free — aperture problem.
Answer

Corner window: flow \((-0.5,-0.5)\). Edge window: not uniquely solvable. Track corners, not edges.

Tracking by detection

Run a detector every frame, then associate boxes across time (nearest neighbour, Hungarian algorithm, appearance embeddings). No explicit motion model — identity comes from matching. Works when the detector is reliable; struggles with occlusion and ID swaps. OpenCV’s face tracker is Camshift (mean-shift on a colour histogram). SIFT-based trackers oversample local features on (flat) objects.

Mean-shift tracking

Represent the target by a colour histogram (or kernel-weighted histogram). In the next frame, place a window at the last position and mean-shift it uphill on the similarity surface (Bhattacharyya / histogram back-projection) until it sits on the object. Camshift additionally adapts window size. Same algorithm as Session 11, now in \((x,y)\) on a probability map instead of \((R,G,B,x,y)\). Comaniciu, Ramesh, Meer: Kernel-Based Object Tracking.

Kalman filters

Observations \(Z\) are noisy; we have a model of how the state \(X\) evolves. The Kalman filter is the optimal predictor–corrector when the system is linear and noise is Gaussian. Scenarios from class: a bird through a forest, a missile blip every few seconds, planets with intermittent observations.

Toy 1-D model: position \(X\), constant velocity \(X'\), interval \(\Delta\), plus Gaussian process noise (wind, etc.).

Predict (time update)
Propagate the state and its covariance to the next time: where should the object be, and how unsure are we?
Compute Kalman gain \(K\)
\(K = P^- H^\top (H P^- H^\top + R)^{-1}\). If measurement noise \(R\) is huge, \(K\to0\) (trust the model). If the prediction is uncertain, \(K\to1\) (trust the sensor).
Update (measurement update)
Correct: \(\hat{x} = \hat{x}^- + K(z - H\hat{x}^-)\). Then update covariance. Repeat.

Mini numerical — 1-D gain. Predicted position \(10\), predicted variance \(P^-=4\), measurement \(z=12\) with \(R=4\), \(H=1\). Gain \(K=4/(4+4)=0.5\). Updated state \(10+0.5(12-10)=\mathbf{11}\) — split the difference because model and sensor are equally trusted.

DNN architectures for tracking

Modern trackers combine a detector with learned appearance and a motion prior. Named in class: DeepSORT (Kalman + CNN embeddings + Hungarian association on top of a detector) and FairMOT (joint detection and re-ID in one network). Handout extras: SiamFC (Siamese similarity), GSDT, SMILEtrack, SPARSEtrack. Use case: pedestrian tracking. Traditional vs DNN: hand-crafted histograms / LK corners vs learned features that survive occlusion, at a GPU cost.

Key takeaways

◆ Remember these
  • Detection = “is there motion?” Tracking = “this is the same object at a new pose.”
  • Optical flow: \(I_x u + I_y v + I_t = 0\). Aperture problem; LK solves it in a window whose \(M\) is Harris-well-conditioned (corners).
  • Mean-shift / Camshift climb a colour-similarity surface. Kalman: predict then correct; \(K\) blends model vs measurement.
  • Tracking-by-detection + DeepSORT/FairMOT is the current default stack.
