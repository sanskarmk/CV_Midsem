Solution — Q9(b)

Assign (nearest centre)
\(1\to c_1\) (dist 0 vs 7); \(2\to c_1\) (1 vs 6); \(6\to c_2\) (5 vs 2); \(7\to c_2\); \(8\to c_2\).
Clusters
\(\{1,2\}\) and \(\{6,7,8\}\).
Update
\(c_1=(1+2)/2=1.5\), \(c_2=(6+7+8)/3=7\).
Converged?
Re-assign with \((1.5, 7)\): \(1,2\) still to \(c_1\); \(6\) is closer to 7 than to 1.5 (dist 1 vs 4.5) → same clusters. Yes, converged after one iteration.
Answer

New centres \(1.5\) and \(7\). Clusters \(\{1,2\}\) and \(\{6,7,8\}\). Converged. Always converges; may be a local min — you still pick \(K\).

P9.2 How does mean-shift segmentation differ from k-means? How is the same idea used as a detector? 2M
Answer

Mean-shift does not pick \(K\). Every point climbs the density (kernel) until a mode; points that fall into the same mode are a cluster. Bandwidth \(h\) replaces \(K\).

As a detector: run mean-shift on a colour / back-projection map; each mode is an object centre — no sliding window, no CNN. Breaks when colour is not distinctive. Camshift is this idea in tracking.

P9.3 One sentence each: EM/MoG vs k-means; agglomerative clustering. 2M
Answer

EM/MoG: soft assignment (ownership probabilities) + elliptical blobs with mixing weights; k-means is hard assignment + spherical clusters of equal weight.

Agglomerative: start with every point a cluster, repeatedly merge the closest pair (linkage = hyperparameter). No initial centres; you cut the dendrogram.
