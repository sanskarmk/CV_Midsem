EQ1 · Pre-midsem recap 4M

(a) Why does SIFT use Difference-of-Gaussians rather than a raw Laplacian? 2M

(b) RANSAC with 30% outliers, minimal sample \(s=2\), success probability 99%. Roughly how many iterations? 2M

Solution

(a)
DoG \(\approx\) scale-normalised LoG but is almost free from the Gaussian pyramid. Extrema in \((x,y,\sigma)\) give scale-invariant blobs.
(b)
\(N=\log(1-p)/\log(1-(1-e)^s)=\log(0.01)/\log(1-0.7^2)=\log(0.01)/\log(0.51)\approx 6.6\) → 7.
Answers

(a) Cheap LoG via the pyramid. (b) About 7 iterations. This is the 10–20% pre-midsem slice.

EQ2 · Softmax + kNN 5M

(a) Scores \(s=(0,\,2,\,2)\), true class 0. Softmax and CE. 3M

(b) Train: \((0,0)\) A, \((4,0)\) B, \((0,4)\) B. Query \((1,1)\), \(k=1\). Label? 2M

Solution

(a) Exp
\(e^0=1,\ e^2=7.389\) twice. Sum \(=15.778\). \(p\approx(0.063,\,0.468,\,0.468)\). \(L=-\log 0.063\approx 2.76\).
(b)
\(d(A)=\sqrt{2}\approx1.41\); \(d(B_1)=\sqrt{9+1}\approx3.16\); \(d(B_2)\) same. \(k=1\) → A.
Answers

(a) Model is confident on the wrong classes → large CE. (b) Label A. Tune \(k\) on val, not test. Binary → sigmoid+BCE; multilabel → per-label sigmoid.

EQ3 · k-means + ViT 6M

(a) Points \(0,1,4,10\). \(K=2\), \(c=(0,10)\). One k-means iteration. 3M

(b) \(224\times224\) image, patch 16. Tokens into ViT (with [CLS])? Why pos-emb? When does ViT beat ResNet? 3M

Solution

(a) Assign
\(0,1\to c_1\) (near 0); \(4\to c_1\) (dist 4 vs 6); \(10\to c_2\). Centres: \(c_1=(0+1+4)/3=\mathbf{5/3}\), \(c_2=\mathbf{10}\).
(b)
\(14^2+1=\mathbf{197}\) tokens. Attention is permutation-invariant → add positions. ViT wins after ImageNet-21k / JFT-scale pretraining; on 1k, ResNet inductive bias wins. Segmentation: per-patch labels + decoder / SAM.
Answers

(a) Centres \(1.67\) and \(10\). (b) 197 tokens; pos-emb; data diet. Do not derive \(QK^\top/\sqrt{d}\) in the hall — write the formula and the \(\sqrt{d}\) reason (softmax saturation).

EQ4 · IoU + U-Net 6M

(a) GT \([0,0,5,5]\), pred \([0,0,4,10]\). IoU? TP at 0.5? 3M

(b) How does an FCN differ from a classifier CNN? Role of U-Net skips and transpose conv? 3M

Solution

(a) Intersection
\([0,0,4,5]\) → \(4\times5=20\). Areas \(25\) and \(40\). Union \(25+40-20=45\). \(\mathrm{IoU}=20/45=4/9\approx0.44\) → FP at 0.5.
(b)
FC: last layers are \(1\times1\) convs → a score map. Skips copy high-res encoder features so pooling does not kill edges. Transpose conv = learned upsample (“deconvolution does not exist”).
Answers

(a) \(\approx0.44\), FP. (b) Map not vector; skips for localisation; transpose conv to go back up.

EQ5 · Detection ladder 8M

(a) \(80\times80\) image, \(20\times20\) window, stride 10. Window count? 2M

(b) One sentence each: Fast vs R-CNN, Faster vs Fast, YOLO vs Faster. YOLO v1 tensor size for 7×7, 2 boxes, 20 classes. 6M

Solution

(a)
\(((80-20)/10+1)^2=7^2=\mathbf{49}\) windows.
(b)
Fast: CNN once + RoI pool (not 2000 warps). Faster: RPN shares features. YOLO: no proposals, one shot, ~7× faster, lower mAP. Tensor \(7\times7\times30=\mathbf{1470}\). Anchors = out of syllabus.
Answers

49 windows; 1470 outputs. Mask R-CNN = Faster + mask head.

EQ6 · LK + Kalman 6M

(a) \(\sum I_x^2=4,\ \sum I_y^2=1,\ \sum I_x I_y=0,\ \sum I_x I_t=-2,\ \sum I_y I_t=0\). Unique flow? Classify the patch. 3M

(b) \(P^-=1\), \(R=4\), \(\hat{x}^-=0\), \(z=10\). \(K\) and \(\hat{x}\). 3M

Solution

(a)
\(M=\mathrm{diag}(4,1)\), invertible but \(\lambda\) unbalanced → edge-ish (one dominant gradient). Formal unique solution \((u,v)=(-2/4,\,0)=(-0.5,\,0)\), but KLT prefers both \(\lambda\) large and similar (corners). Aperture: the small \(\lambda_y\) is noisy.
(b)
\(K=1/(1+4)=0.2\), \(\hat{x}=0+0.2(10)=\mathbf{2}\). Trust the model; the sensor is noisy.
Answers

(a) Unique numbers exist but the patch is a poor track point. (b) \(K=0.2\), \(\hat{x}=2\). DeepSORT = Kalman + embeddings + Hungarian.

EQ7 · AP + edge design 5M

(a) 2 GT. Ranked: TP, FP, TP. 11-point AP (interpolate). 3M

(b) Warehouse person-in-bay, <100 ms, 8 W, no cloud. Board + model in one line. 2M

Solution

(a) Running
R1: \(P=1, R=0.5\). R2: \(P=0.5, R=0.5\). R3: \(P=2/3, R=1\).
(a) Interpolate
Knots \(0\)–\(0.4\): max P = 1.0. Knots \(0.5\)–\(1.0\): max P = \(2/3\) (the last TP). \(\mathrm{AP}=(5\times1 + 6\times 2/3)/11=(5+4)/11=\mathbf{9/11}\approx0.82\).
(b)
Coral or Jetson Nano + INT8 YOLO-tiny / SSD-MobileNet; not Faster R-CNN, not SAM. Quote mAP, ms on that board, W.
Answers

(a) \(\mathrm{AP}\approx0.82\). (b) Constraint → board → tiny one-stage detector → INT8 → (mAP, ms, W). Face/OCR if asked: cascade + TAR@FAR; CER = edit distance / length.
