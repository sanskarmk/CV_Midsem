Visual Bag of Words & Semantic Hierarchy

How an image becomes a histogram of “visual words,” and how that histogram is used for scene labelling, semantic understanding, and patch classification (the breast-tumour use case in the handout). From pixels to words

A raw image is a huge vector. Matching it with \(L_2\) fails under pose and lighting. BoW throws away exact geometry and keeps what kinds of local stuff appeared — the same trick as a document classifier that ignores word order. Two faces of different people still share a characteristic mix of eye/nose/mouth patches; two cats share whisker/fur/ear words.

The BoW pipeline

Detect & describe
SIFT/Harris/dense grid → local descriptors (the “patches” / “blobs”).
Codebook
k-means on a huge pool of training descriptors. The \(K\) centres are visual words. \(K\) is a hyperparameter (often 200–5000).
Quantize
Each descriptor → nearest word (vector quantization). Optional: soft assignment / VLAD / Fisher vectors for a richer encoding.
Histogram
\(K\)-bin count (then \(L_1\) or \(L_2\) normalise). Optional spatial pyramid: repeat at 1×1, 2×2, 4×4 grids and concatenate — a cheap semantic hierarchy of layout.
Classify
SVM / kNN / linear on the histogram. This is “summarizing images with visual words” in the handout.

Knowledge representation

Classic vision needed an explicit model of the world, not just a histogram:

  • Semantic hierarchy / ontology — “poodle ⊂ dog ⊂ animal ⊂ object.” A classifier that knows the tree can transfer: evidence for “dog” supports “animal.” WordNet-style taxonomies and ImageNet’s synsets are this idea at dataset scale.
  • Part–whole — a face is eyes + nose + mouth in a constrained layout (constellation / pictorial-structure models).
  • Attributes — furry, wheeled, four-legged — shared across classes so rare classes still have features.

BoW is a flat representation. The pyramid and the ontology are how you put hierarchy back in without going all the way to a CNN.

Syntactic pattern recognition

If BoW is a bag (orderless), syntactic methods treat an object as a sentence generated by a grammar of parts: a bicycle = two wheels + frame in a legal arrangement. Production rules reject illegal parses (a wheel floating in the sky). Scene grammars (And-Or graphs) do the same for rooms: a bedroom → bed + wardrobe, not a bed + traffic light. This is the handout’s “syntactic pattern recognition” — complementary to statistical BoW, and the ancestor of today’s scene-graph models.

Scene labelling

Scene labelling / semantic image understanding assigns a class to every region (sky, building, tree, road) using both local appearance (the visual-word histogram of the region) and contextual compatibility (sky is above road). MRFs / CRFs were the classic glue; FCNs (Session 12) learned that compatibility inside the net. The BoW histogram of the whole image is also a cheap scene classifier (“this is a kitchen”) before you label pixels.

Use case — patch classification of breast tumours

Handout application: slide a window over a histopathology image, describe each patch with visual words (or a CNN, today), classify tumour vs normal. Why BoW still makes sense here: stain colour varies, but local texture words (nuclei density, gland structure) are stable; a codebook trained on many slides absorbs stain variation better than raw RGB. Metrics: patch accuracy, then whole-slide aggregation (majority vote / heatmap) — same P/R/F1 as Session 16.

Key takeaways

◆ Remember these
  • BoW: SIFT patches → k-means codebook → histogram → classifier. Invented for vision; NLP reused it.
  • Spatial pyramid = a cheap semantic hierarchy of layout. Ontology = class hierarchy.
  • Syntactic PR = grammars of parts; scene labelling = appearance + context.
  • Handout use case: tumour patch classification from visual words.
