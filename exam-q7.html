📄 Question

Q7(a) Training points: \(A=(0,0)\) cat, \(B=(0,2)\) cat, \(C=(3,0)\) dog, \(D=(3,3)\) dog. Query \(q=(1,1)\). Using Euclidean distance, classify with \(k=1\) and \(k=3\). Why must \(k\) be chosen on the validation set, not the test set? 4M

Q7(b) A 3-class linear classifier outputs scores \(s=(1.0,\, 3.0,\, 0.0)\). The true class is class 1. Compute the softmax probabilities and the cross-entropy loss. 2M

Solution — Q7(a)

Distances to \(q=(1,1)\)
\(d(A)=\sqrt{1+1}=\sqrt{2}\approx1.41\); \(d(B)=\sqrt{1+1}=\sqrt{2}\approx1.41\); \(d(C)=\sqrt{4+1}=\sqrt{5}\approx2.24\); \(d(D)=\sqrt{4+4}=\sqrt{8}\approx2.83\).
\(k=1\)
Two-way tie \(A\) and \(B\), both cats → cat. (If the examiner wants a unique nearest, break ties by index / smaller \(x\); both still cat.)
\(k=3\)
Nearest three: \(A\) cat, \(B\) cat, \(C\) dog. Majority = cat.
Why validation
The test set is used once to report generalisation. Tuning \(k\) on test leaks the answer and overfits. Train fits; val picks hyperparameters (\(k\), metric); test is the sealed exam.
Answer

\(k=1\) → cat; \(k=3\) → cat. Choose \(k\) on validation, never on test.

Solution — Q7(b)

\[ p_c = \frac{e^{s_c}}{\sum_j e^{s_j}}, \qquad L=-\log p_y \]
Exponentials
\(e^{1}=2.718,\ e^{3}=20.086,\ e^{0}=1\). Sum \(=23.804\).
Softmax
\(p\approx(0.114,\, 0.844,\, 0.042)\).
True class is 1
\(L=-\log 0.844 \approx 0.170\).
Answer

\(p\approx(0.11,\,0.84,\,0.04)\), \(L\approx0.17\). Confident and correct → small loss. Binary problems use sigmoid + BCE; multilabel uses a sigmoid per label, not one softmax.

P7.3 Distinguish binary vs multiclass vs multilabel losses. 2M
Answer

Binary (yes/no): one logit, sigmoid + binary cross-entropy.

Multiclass (exactly one of \(C\) labels): softmax + CE — mutually exclusive.

Multilabel (cat and indoor): a sigmoid per label, sum of BCEs — not a single softmax, because two labels can both be true.

P7.4 Why is “number of mistakes” a bad training loss for a linear classifier? 1M
Answer

It is discrete (no useful gradient, can’t break near-misses from disasters) and does not encourage a margin. Softmax/CE is continuous and punishes a low probability on the true class even when \(\arg\max\) is already correct.
