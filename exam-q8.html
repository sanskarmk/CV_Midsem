Attention, Scaled Dot-Product & Vision Transformers

Session 10. He said: do not derive attention in the hall — know Q/K/V, why \(\sqrt{d}\), positional embeddings, and the ViT pipeline.

📄 Question

Q8(a) What problem of classical seq2seq does attention fix? Define Q, K, V and write the scaled dot-product formula. Why divide by \(\sqrt{d}\)? 3M

Q8(b) Sketch the ViT classification pipeline. When does a ViT beat a ResNet, and why? How can the same backbone be used for segmentation? 3M

Solution — Q8(a)

Classical encoder–decoder crushes the whole source into one context vector. Late decoder steps forget the start of a long sentence — a representational bottleneck.

Attention lets each output step score every encoder state and take a weighted sum. For self-attention on a sequence \(X\):

\[ Q=XW_Q,\quad K=XW_K,\quad V=XW_V, \qquad \mathrm{Attention}(Q,K,V)=\mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d}}\right)V \]

\(Q\) = “what am I looking for”, \(K\) = “what do I contain”, \(V\) = “what do I pass on”. The softmax of the scores is the attention weights \(\alpha\).

Why \(\sqrt{d}\)

Dot products of \(d\)-dimensional unit-ish vectors have variance \(\propto d\). For \(d=64\), unscaled scores are huge, softmax saturates (tiny gradients). Dividing by \(\sqrt{d}\) keeps logits in a healthy range. You will not be asked to derive this — state it.

Solution — Q8(b)

Patch
Split the image into e.g. \(16\times16\) patches; flatten each; linear-project to a token.
[CLS] + pos-emb
Prepend a learnable class token. Add positional embeddings (transformers have no built-in order).
Encoder
Stack of self-attention + MLP blocks. Read the [CLS] token (or pool) → linear classifier.
Data diet
On ImageNet-1k, ViT loses to ResNets (too little data for a low-bias model). On ImageNet-21k / JFT-300M, large ViTs match then beat large ResNets — less inductive bias, so they need a pretraining feast. CNNs bake in locality; ViTs must learn it.
Segmentation
Emit a label per patch (or upsample tokens) + a decoder / promptable mask head (SETR, SegFormer, SAM). U-Net still wins on small medical sets; SAM when you can prompt.
Model answer

Patches → tokens + [CLS] + pos-emb → transformer → class scores. ViT beats ResNet only after large-scale pretraining. For segmentation, keep the encoder and add a decoder; do not claim ViT-as-classifier is already a segmenter.

Practice questions

P8.1 Softmax attention weights for scores \(s=(2.0,\, 0.0,\, 0.5)\). 2M
Exponentials
\(e^{2}=7.389,\ e^{0}=1,\ e^{0.5}=1.649\). Sum \(=10.038\).
Weights
\(\alpha\approx(0.736,\, 0.100,\, 0.164)\).
Answer

The query puts ~74% of its mass on token 1. Context = \(0.736\,v_1 + 0.100\,v_2 + 0.164\,v_3\).

P8.2 A \(224\times224\) image, patch size \(16\). How many patch tokens does ViT see (before [CLS])? 1M
Answer

\((224/16)^2 = 14^2 = \mathbf{196}\) tokens. Plus 1 [CLS] → 197 into the encoder.

P8.3 Why does a transformer need positional embeddings? 1M
Answer

Self-attention is a set operation — permuting tokens does not change the output. Vision and language are ordered, so we add a position vector (learned or sinusoidal) to each token. Without it, “the cat sat” = “sat cat the”, and a top-left patch equals a bottom-right one.

P8.4 “CNNs are Robin to Transformers’ Batman” — what did he mean, and what is still CNN’s job? 1M
Answer

Since ViT, transformers own the SOTA headlines; CNNs remain the default feature extractor (backbones of Faster R-CNN, U-Net, MobileNet on edge). On small data the conv prior still wins.
