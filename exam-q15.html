📄 Question

Q15(a) A factory gate camera must recognise a number plate in < 80 ms, no cloud, ~10 W, night IR. Sketch board + model + pipeline and the three numbers you would quote. Why not Faster R-CNN or SAM? 4M

Q15(b) Why was Viola–Jones real-time in 2001? Name two DNN face models and the metric TAR @ FAR = \(10^{-3}\). GT text BITS, OCR B1TS: CER? 3M

Solution — Q15(a)

Constraint
< 80 ms, 10 W, on-prem, IR night → edge GPU/TPU, not a cloud ViT.
Board
Jetson Nano / Orin Nano, or Coral if you can compile INT8 TFLite. Pi CPU-only will miss 80 ms on a decent detector. ESP32 is too small for plate OCR.
Model
INT8 YOLO-tiny / SSD-MobileNet for the plate box; a tiny CRNN / Tesseract-lite for the crop. Depthwise-separable (MobileNet/Xception) is why classification fits a Pi.
Pipeline
Capture → letterbox → detect plate → warp crop → OCR → regex (state format) → GPIO / log. No video uplink (privacy + bandwidth).
Quote
mAP @ 0.5 on an in-domain night set, latency on that board, watts at the wall. FLOPs alone are not latency.
Why not Faster / SAM

Faster R-CNN is two-stage (RPN + head) — too slow/heavy for 80 ms on 10 W. SAM is a promptable foundation model; it belongs in the cloud. Shape: constraint → board class → model family → quantisation → on-device post-process → (mAP, ms, W).

Solution — Q15(b)

Viola–Jones
Haar features in \(O(1)\) via the integral image; AdaBoost picks a few of them; an attentional cascade rejects most non-face windows after 1–2 features. Only survivors pay for later stages → real-time on 2001 CPUs.
DNN faces
MTCNN (propose → refine → landmarks), RetinaFace (single-shot + landmarks). FastFace for edge/attendance.
TAR @ FAR
True-accept rate at a fixed false-accept rate — the operating point a bank cares about (how many real users you let in while keeping impostors at \(10^{-3}\)).
CER
GT BITS, OCR B1TS: one substitution (I→1), length 4 → \(\mathrm{CER}=1/4=25\%\). Word accuracy is 0 — quote both.
Answer

Cascade + integral image; MTCNN / RetinaFace; TAR@FAR is the verification point; \(\mathrm{CER}=25\%\). WER uses the same edit distance at word level.

Practice questions

P15.1 A 3×3 conv on \(C=32\) channels vs depthwise-separable: muls per pixel? 2M
Standard
\(9C^2=9\times1024=9216\)
DW + PW
\(9C + C^2=288+1024=1312\) ≈ \(7\times\) cheaper
Answer

9216 vs 1312. That is why MobileNet/Xception appear next to classification metrics in the handout.

P15.2 Match board to job: ESP32-CAM, Raspberry Pi, Jetson Orin, Coral. 2M
Answer

ESP32: motion trigger / JPEG, not YOLO-v8. Pi: OpenCV + MobileNet. Coral: INT8 TFLite only, high IPS/W. Orin: TensorRT / DeepStream multi-cam. Intel NUC: OpenVINO + Movidius stick.

P15.3 OCR pipeline in three steps. LayoutLM / DiT — what are they for? 2M
Answer

Localise text → recognise (CTC/transformer) → lexicon/regex post-process. LayoutLM / DiT are document transformers for layout (tables, invoices), not just glyph reading. Plate/invoice are the handout use cases.
