Attention, Transformers & Vision Transformers

A CNN is a stack of local filters. A transformer lets every token look at every other token. Vision Transformer (ViT) takes that NLP architecture, chops an image into patches, and classifies with almost no convolutions.

The encoder–decoder bottleneck (review)

Classic seq-to-seq translation: an encoder reads the source sentence into hidden states; a single context vector \(c\) (often just the encoder’s last hidden state) is handed to a decoder that generates the target. Forcing the whole source through one vector is a representational bottleneck — later decoder steps forget the beginning of a long sentence. Teacher forcing feeds the ground-truth previous token during training rather than the model’s own softmax output.

◆ The bank / river-bank problem

Without attention, every decoder step sees the same static \(c\). With attention, the decoder builds a different, dynamic context at each step — a weighted sum of all encoder hidden states, focused on the source words that are relevant right now. “Bank” in “river bank” attends to different encoder states than “bank” in “bank account.”

Attention in three steps

At decoder step \(i\), with decoder state \(s_i\) and encoder states \(h_j\):

Score
How relevant is each encoder state to the current decoder state? Dot-product attention: \(\text{score}(s_i, h_j)=s_i^\top h_j\). A learned bilinear form \(s_i^\top W_s h_j\) is more powerful — \(W_s\) is trained end-to-end.
Normalise
Softmax the scores to weights \(\alpha_{i,j}\) — a distribution over source positions.
Context
\(c_i = \sum_j \alpha_{i,j}\, h_j\) — a weighted average of encoder states. The decoder now “attends to” a particular part of the source.

Transformers — “Attention Is All You Need”

Vaswani et al., NeurIPS 2017. A transformer maps a sequence of input vectors \((x_1,\ldots,x_n)\) to a sequence of output vectors \((y_1,\ldots,y_n)\) of the same length. The key block is self-attention: comparisons are to other elements of the same sequence. No recurrent connections ⇒ every time step is independent ⇒ parallel (unlike LSTMs) and easy to scale.

Self-attention = the ability to compare an item of interest to a collection of other items so their relevance in the current context is revealed.

Query, key, value

Each input embedding \(x_i\) plays three roles, via three learned \(d\times d\) matrices (Vaswani used \(d=1024\)):

RoleIntuition
Query \(Q\)The current focus of attention — “what am I looking for?”
Key \(K\)A preceding input being compared to that focus — “what do I contain?”
Value \(V\)The content actually mixed into the output — “what do I contribute?”

Pack the \(N\) embeddings as rows of \(X\). Compute \(Q=XW_Q\), \(K=XW_K\), \(V=XW_V\). Scaled dot-product attention (the raw dot product can be huge, which saturates softmax):

\[ \mathrm{Attention}(Q,K,V)=\mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d}}\right)V \]

Each output \(y_i\) is computed independently, so the whole sequence is parallel. Causal (left-to-right) LMs zero the upper triangle of the score matrix (set to \(-\infty\) before softmax) so position \(i\) cannot look into the future.

Multi-head attention and positional embeddings

Words relate in many ways at once (syntax, coreference, …). One self-attention layer is not enough. Heads = parallel self-attention layers at the same depth, each with its own \(W_Q,W_K,W_V\). Concatenate their outputs and project back to \(d\) so blocks can be stacked. Add LayerNorm and an MLP inside each transformer block.

Self-attention is permutation-invariant — it doesn’t know order. Fix: add a positional embedding to each token embedding. The original transformer used sines and cosines of different frequencies; ViT uses a learned vector per patch position.

Vision Transformer (ViT)

Dosovitskiy et al., ICLR 2021 — “An Image is Worth 16×16 Words.” Take a standard NLP transformer and feed it image patches instead of word tokens.

Patchify
A \(224\times224\) image is split into a \(14\times14\) grid of \(16\times16\) RGB patches (or \(16\times16\) of \(14\times14\)). Each patch is shape \(3\times16\times16\). Smaller patch size ⇒ more patches ⇒ bigger model. One attention matrix has \(14^4=38{,}416\) entries (~150 KB); 48 layers × 16 heads ⇒ ~112 MB of attention maps.
Linear projection
Flatten each patch and map it to a \(D\)-dimensional token. (This first layer is secretly a convolution: Conv2D(p×p, 3→D, stride=p). The MLPs inside the transformer are stacks of \(1\times1\) convolutions. So “no convolutions” is not quite true.)
Add position + [CLS]
Add a learned \(D\)-dim positional embedding per patch, and prepend a special learned classification token.
Transformer encoder
Exact same architecture as NLP. The [CLS] output is linearly projected to \(C\) class scores.
◆ ViT is also a segmenter (handout module 4)

The same patch-token backbone can emit a label per patch (or upsample tokens to pixels) instead of a single [CLS] score — SETR / SegFormer / SAM’s image encoder are this idea. For the exam: ViT classified in Session 10; for segmentation you still need a decoder (or a promptable mask head like SAM). U-Net remains the default when data is small (MRI); SAM when you can prompt.

ViT vs ResNets — the data diet

Pretraining dataResult on ImageNet (after fine-tune)
ImageNet-1k (1.2M / 1k classes)ViT worse than ResNets — not enough data for a low-bias model.
ImageNet-21k (14M / 21k classes)Big ViTs match big ResNets (BiT = ResNet-152×4).
JFT-300M (300M labelled, internal Google)Large ViTs outperform large ResNets, and use hardware more efficiently (matmul vs conv). ViT: ~2.5k TPU-v3 core-days vs ResNet ~9.9k.

Notation: B / L / H = Base / Large / Huge; /32, /16, /14 = patch size (smaller patch = more tokens = bigger model).

◆ Less inductive bias, more data

The claim in the paper: ViTs have less inductive bias than ResNets (no built-in locality / translation equivariance beyond the first patch layer), so they need more pretraining data to learn good features. On small data, the convolutional prior wins; at JFT scale, the transformer pulls ahead. Variants you’ll see named: DeiT (data-efficient training), Swin (shifted windows), CLIP-style ViTs for vision–language.

Key takeaways

◆ Remember these
  • Attention = score → softmax weights → weighted sum of values. Removes the seq2seq bottleneck.
  • Transformer = stacked self-attention + MLP, fully parallel. Multi-head = several relations at once.
  • \(\mathrm{softmax}(QK^\top/\sqrt{d})\,V\). Position is added, not inherent.
  • ViT: patches → tokens + [CLS] + pos-emb → transformer → class scores. Needs large-scale pretraining to beat ResNets.
