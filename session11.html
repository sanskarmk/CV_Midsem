Session 11

Image Segmentation

Divide an image into regions that are more meaningful than raw pixels — so we can locate objects and boundaries. Classic methods cluster pixels by colour and position (k-means, mixtures of Gaussians, mean-shift) before deep nets take over in the next session.

Types of segmentation

KindWhat it does
SemanticLabel every pixel with a class (car, tree, road). Instances of the same class are not separated.
InstanceLike semantic, but different objects of the same class get different IDs (car #1 vs car #2).
PanopticBoth: stuff classes (sky, road) + thing instances (each car).
ThresholdingSimplest: pixel is foreground iff intensity \(\ge T\).
Edge-basedFind objects from sharp intensity changes (Canny, then fill).
Region-basedGroup pixels that look similar in colour / intensity / texture.

Gestalt: seeing the unified whole

Humans perceive an object in its entirety before its parts. “What is an object?” is subjective, but Gestalt laws try to formalise grouping: proximity, similarity, continuation, closure, common fate. Two algorithmic strategies:

Top-down

Pixels belong together because they come from the same object (need recognition).

Bottom-up

Pixels belong together because they look similar (clustering on colour / texture / position).

This session is bottom-up. Next session (FCN, U-Net) is learned, closer to top-down.

Histogram-based segmentation and k-means

A histogram counts how often each colour occurs. Modes of the histogram ≈ dominant colours ≈ segments. Goal: break the image into \(K\) regions by reducing it to \(K\) representative colours and mapping every pixel to the closest one. Choosing those colours is a clustering problem: minimise the sum of squared distances from each point to its nearest centre.

k-means (the algorithm from the slides):

Initialise
Randomly pick cluster centres \(c_1,\ldots,c_K\).
Assign
For each point \(p\), put it in the cluster of the closest \(c_i\).
Update
Set \(c_i\) to the mean of points in cluster \(i\).
Repeat
Until centres stop moving. Always converges; can be a local minimum of the objective — different inits give different answers. You must choose \(K\).

k-means, live

Step through assignment and update on a 2-D colour-like scatter. Watch centres jump, then settle:

Worked numerical — one k-means iteration

Q. Points \(2, 3, 8, 10\). \(K=2\), initialise \(c_1=2,\ c_2=8\). Perform one full iteration (assign + update).

Assign
\(2\to c_1\), \(3\to c_1\) (dist to 2 is 1, to 8 is 5); \(8\to c_2\), \(10\to c_2\).
Update
\(c_1=(2+3)/2=2.5\), \(c_2=(8+10)/2=9\).
Answer

After one iteration: clusters \(\{2,3\}\) and \(\{8,10\}\); centres \(2.5\) and \(9\). Next assign still gives the same clusters → converged.

Mixture of Gaussians and EM

k-means gives hard assignments and spherical clusters. A generative model instead assumes points were sampled from a continuous density with parameters \(\theta\). A mixture of Gaussians (MoG) is \(K\) blobs with means \(\mu_b\), covariances \(V_b\), mixing weights \(\pi_b\). The likelihood of a point is a weighted sum of Gaussians.

Expectation–Maximisation (EM) maximises that likelihood:

E-step
Given current blobs, compute the ownership probability that point \(x\) belongs to blob \(i\).
M-step
Given ownerships, update \(\pi_b, \mu_b, V_b\) to maximise likelihood (weighted mean and covariance).
Repeat
Until convergence.

Applications named in class: any clustering, any model estimation, missing data, outliers, colour segmentation, motion segmentation, foreground/background. Problems: local minima; you still need to know \(K\); you must choose the generative family.

Agglomerative clustering (handout)

Start with every pixel (or superpixel) as its own cluster. Repeatedly merge the closest pair until you have \(K\) regions or a distance cutoff. Linkage (single / complete / average / Ward) is the hyperparameter. Unlike k-means you don’t pick centres first — you grow a dendrogram. Costly on raw pixels, fine on SLIC superpixels.

DNN segmenters named in the handout

Detectron family (Mask/Faster R-CNN zoo), SOLO / CondInst (instance seg without / with dynamic filters), SAM (promptable foundation model — points/boxes → mask), InternImage (large conv backbone). Satellite crop classification is the listed use case.

Mean-shift

Non-parametric mode seeking — you do not pick \(K\). For images, run in \((R,G,B,x,y)\) so nearby similar-coloured pixels group together (Comaniciu & Meer).

Kernel density
The data define a smooth density (Gaussian kernel of chosen bandwidth).
Climb
For each point: centre a window, compute the mean (centre of mass) of points in it, shift the window there, repeat until it stops. The shift vector always points uphill.
Cluster
Points whose trajectories end at the same mode share an attraction basin → one segment.

Pros

Good general-purpose segmentation; flexible number and shape of regions; robust to outliers.

Cons

Must choose kernel size in advance; not suitable for high-dimensional features. Use for oversegmentation, multiple segmentations, tracking, clustering, filtering.

Key takeaways

◆ Remember these
  • Semantic vs instance vs panoptic; bottom-up (looks similar) vs top-down (same object).
  • k-means: assign to nearest centre, replace centre by mean. Always converges; local min; you pick \(K\).
  • EM / MoG: soft assignments + covariance. Same local-min / must-know-\(K\) issues.
  • Mean-shift: climb the KDE to modes; \(K\) is discovered. Bandwidth is the hyperparameter.
  • Agglomerative: merge closest pair (handout). SAM / Detectron / U-Net for learned seg.
