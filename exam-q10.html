IoU, Fully Convolutional Nets & U-Net

Session 12. He flagged IoU of two boxes as “the sort of problem statement you can expect in your semester exams.”

📄 Question

Q10(a) Ground-truth box \([x_1,y_1,x_2,y_2]=[0,0,6,6]\), prediction \([2,2,8,8]\). Compute IoU. Is this a true positive at PASCAL’s threshold 0.5? At 0.3? 4M

Q10(b) How do you turn a classifier CNN into a semantic segmenter? Why skip connections in U-Net? What is transpose convolution for? 4M

Solution — Q10(a)

\[ \mathrm{IoU}=\frac{|A\cap B|}{|A\cup B|}=\frac{\mathrm{TP}}{\mathrm{TP}+\mathrm{FP}+\mathrm{FN}} \]
Intersection
\([2,2,6,6]\) → width \(4\), height \(4\) → area \(16\).
Box areas
GT \(6\times6=36\), pred \(6\times6=36\).
Union
\(36+36-16=56\).
IoU
\(16/56=2/7\approx\mathbf{0.286}\).
Thresholds
PASCAL 0.5: \(0.286<0.5\) → FP. At 0.3 still FP (\(0.286<0.3\)). Duplicate detections of the same GT: first TP, rest FP.
Answer

\(\mathrm{IoU}=16/56\approx0.29\) → false positive at 0.5 and at 0.3. Accuracy is the wrong metric here (a detector that says “nothing” everywhere is ~99% accurate).

Solution — Q10(b)

FCN
Replace the last fully-connected layers with \(1\times1\) convolutions. The net now emits a coarse map of class scores for any spatial size (Long et al., 2014).
U-shape
Downsample (conv+pool) for context, then upsample back to input resolution. “If I have pooled, I’ll unpool. If I have convolved, I’ll do transpose convolution.” True deconvolution does not exist — we use transpose conv.
Skips
Pooling throws away localisation. U-Net concatenates matching encoder feature maps onto the decoder so edges survive. ResNet residuals are a related “smooth the lost topology” trick so GD can find a minimum.
Model answer

Classifier → FCN by swapping FC for \(1\times1\) conv. U-Net = encoder–decoder + skip concatenations. Transpose conv = learned upsample. mIoU = IoU averaged over classes.

P10.2 Two boxes overlap in a \(2\times2\) square; each box is \(4\times4\). IoU? 2M
Answer

Intersection \(=4\), union \(=16+16-4=28\), \(\mathrm{IoU}=4/28=1/7\approx0.14\).

P10.3 Precision and recall from TP=3, FP=1, FN=2. Why not quote accuracy? 2M
P, R, F1
\(P=3/(3+1)=0.75\), \(R=3/(3+2)=0.60\), \(F_1=2\cdot0.75\cdot0.60/(0.75+0.60)=0.667\).
Answer

\(P=0.75\), \(R=0.60\). Accuracy counts true negatives — in detection almost every window is background, so “never fire” looks accurate.

P10.4 Name two extra segmentation metrics from the handout besides IoU. 1M
Answer

Pixel accuracy (can be fooled by class imbalance) and boundary error (ABPE / BDE — how far predicted contours sit from GT contours). mIoU is the one that punishes missing the small object.
